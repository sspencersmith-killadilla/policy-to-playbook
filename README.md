# Relay- CivicPlexus

Can we build a webapp that allows us to upload a policy document, like a code of conduct, or a written SOP for a process and then the site will create a fully functional training module on that policy? This should allow the user to brand the training for their own org, edit the details, and export as a slideshow or video. What would it take to make this a fully functional product that could be used by organizations in the real world today?
